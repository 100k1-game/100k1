## Как запустить (важно!)

GitHub Pages показывает только страницы. **Связь гостей с ведущим идёт через сервер** — его нужно запустить на компьютере ведущего.

### Шаг 1 — Установите Python и зависимости

```bash
pip install -r requirements.txt
```

### Шаг 2 — Запустите сервер

```bash
python app.py
```

### Шаг 3 — Ведущий открывает в браузере

```
http://localhost:8080/host.html
```

Дождитесь статуса **«Готов принимать гостей»**.

### Шаг 4 — Покажите QR гостям

Нажмите **«Показать QR для гостей»** на панели ведущего.

### Шаг 5 — Гости с телефонов (та же Wi‑Fi сеть)

Замените `localhost` на IP компьютера ведущего, например:

```
http://192.168.1.10:8080/host.html
```

QR-код должен вести на `http://192.168.1.10:8080/index.html?room=КОД`.

Узнать IP: в Windows выполните `ipconfig`, смотрите **IPv4**.

## GitHub Pages

На GitHub можно хранить код, но **квиз запускайте через `python app.py`**, а не через ссылку github.io — иначе гости не смогут подключиться к ведущему.

Если нужен доступ через интернет — разверните `app.py` на [Render.com](https://render.com) (бесплатно) и укажите URL в `static/js/config.js`:

```javascript
const API_BASE = "https://ваш-проект.onrender.com";
```
