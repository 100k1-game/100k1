# Квиз — 5 сентября · День нефтяной и газовой промышленности

Онлайн-квиз с QR-входом для гостей и live-панелью для ведущего.  
Работает на **GitHub Pages** — без Firebase, без серверов, без настройки.

## Как пользоваться

### 1. Опубликуйте на GitHub Pages
Репозиторий → **Settings → Pages** → Branch: **main**, папка **/ (root)** → Save

### 2. Ведущий
1. Откройте **`host.html`**
2. Нажмите **«Показать QR для гостей»**
3. Держите вкладку ведущего **открытой** во время квиза

### 3. Гости
1. Сканируют QR-код
2. Вводят ФИО и специальность
3. Нажимают **«Начать»** и проходят 10 вопросов

### 4. Ведущий видит в реальном времени
ФИО, специальность, баллы и прогресс каждого участника.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/host.html

## QR через Python (опционально)

```bash
pip install qrcode[pil]
python generate_qr.py --url http://ВАШ_IP:8000/index.html?room=КОД
```

Код комнаты виден на панели ведущего.
